# Sistema de Seguimiento para Servicio Social

Plataforma para administrar el servicio social de la Fundación Aprende con Reyhan: registro de estudiantes, cohortes, proyectos con aprobación del tutor, horas e hitos, reportes y un asistente de IA.

## Documentación

- [Presentación del proyecto](docs/presentacion/index.html): ábrela en el navegador (flechas para navegar, `N` para notas, `F` para pantalla completa).
- [Contenido de la presentación](docs/presentacion/CONTENIDO.md): texto de cada diapositiva y notas del orador.
